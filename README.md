# Válora · Carrito de paquetes de catering

Proyecto académico de Joel Robalino, paralelo 2. Permite configurar seis paquetes de catering con distintas comidas y complementos, gestionar un carrito y finalizar la compra con una confirmación. El carrito se vacía al completar el recorrido; WhatsApp no forma parte del cierre. Los precios y la compra son de demostración; no se realiza un cobro real.

Para abrirlo desde VS Code, abre `index.html` con la extensión Live Server. Usa un servidor HTTP local porque el navegador necesita cargar los catálogos JSON mediante Fetch; no abras el archivo directamente con doble clic.

- **Código y recursos:** `index.html`, `privacidad.html`, `condiciones.html`, `assets/`, `data/` y `js/`.
- **Documentación completa:** [instalación, estructura, tecnologías y publicación](documentacion/README.md).
- **Para la exposición:** [guía de defensa](documentacion/GUIA_DEFENSA.md).
- **Auditorías e informes anteriores:** en `documentacion/`.

Las pruebas de desarrollo se retiraron de la entrega final. Las licencias de los recursos se conservan junto a sus archivos en `assets/`. Este README breve se mantiene en la raíz como entrada a la documentación y como parte del entregable.
